# admissions-materials

研究所申請與備審製作 Skill。從當前使用者的申請目標、背景與現有素材開始，不預設學校、個人經歷或排版。

## 工作流程

- 分階段詢問目標、背景與素材，依本次需求接續工作。
- 核對當年度官方申請要求、表件與期限。
- 撰寫自傳與研究計畫前，查核該系組老師、實驗室、研究項目與近期成果，連接使用者經歷與研究興趣。
- 製作自傳、讀書計畫、研究計畫、專題報告及佐證資料。
- 核對個人分工、成果狀態、版本、版面與送件欄位。

## 使用

將此儲存庫內容放入名為 `admissions-materials` 的本機 skills 資料夾；啟用後可使用 `$admissions-materials` 開始。

範例：使用 `$admissions-materials`，先詢問我的申請目標、背景與現有資料，再安排備審工作。

本儲存庫僅包含通用工作流程，不含申請者個資、成績、簽名或個別送件材料。各校要求與研究室資訊須在實際使用時查證。
