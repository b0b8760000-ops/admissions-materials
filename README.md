# 研究所申請與備審製作｜admissions-materials

協助準備研究所申請：從詢問申請目標、背景與現有資料開始，依各系組要求製作自傳、讀書計畫、研究計畫、專題報告及佐證，並協助審閱與送件核對。

**第一次使用不需要先決定所有學校，也不需要一次準備齊全資料。** 可以先說明目前狀況，再分批補充。此 Skill 不內建任何申請者的個資、成績、學校選擇或固定版型。

## 1. 安裝

本儲存庫目前為私人；下載或安裝者必須先具有儲存庫存取權。公開使用說明不會自動授予其他人存取權。

### 方法 A：請 Codex 協助安裝

在可使用 skill-installer 的 Codex 對話中貼上：

```text
使用 $skill-installer，從下列 GitHub 儲存庫安裝 admissions-materials：
https://github.com/b0b8760000-ops/admissions-materials
SKILL.md 位於儲存庫根目錄，請將技能資料夾命名為 admissions-materials。
```

私人儲存庫需要安裝環境已有適當的 GitHub 驗證；只有瀏覽器登入，未必代表安裝工具已有權限。遇到驗證問題可改用下面的手動下載方式，不必把密碼或權杖貼入對話。

### 方法 B：下載後手動放入技能目錄

1. 登入有權限的 GitHub 帳號，開啟本儲存庫，選 **Code → Download ZIP** 並解壓縮。
2. 將解壓後的資料夾命名為 `admissions-materials`，確認 `SKILL.md` 直接位於其中，不要多套一層資料夾。
3. 將整個資料夾放入下列其中一個位置：

| 使用範圍 | 位置 |
|---|---|
| 個人使用，跨專案可用 | `~/.agents/skills/admissions-materials/` |
| 僅供目前專案使用 | `<專案根目錄>/.agents/skills/admissions-materials/` |
| Windows 個人使用的對應位置 | `%USERPROFILE%\.agents\skills\admissions-materials\` |

不要同時安裝到多處而產生同名副本。若現有環境已透過安裝工具管理這個 Skill，沿用該安裝位置即可。

資料夾應包含：

```text
admissions-materials/
├─ SKILL.md
├─ README.md
├─ agents/
│  └─ openai.yaml
└─ references/
   └─ intake-and-checklists.md
```

Codex 會自動偵測技能；若未顯示，可重新啟動後再確認。安裝位置與呼叫方式以 [OpenAI 官方技能說明](https://learn.chatgpt.com/docs/build-skills)及目前使用環境為準。

## 2. 開始使用

在 Codex 輸入 `$admissions-materials`，加上本次需求。若介面提供技能選單，也可選取「研究所申請與備審製作」。

### 從零開始

```text
使用 $admissions-materials，協助我從零準備研究所申請。
請先詢問我的申請目標、背景與現有資料，列出還缺什麼，再安排製作順序。
我還沒有選定學校，資料可以分批提供。
```

助理會先詢問三類資訊；已在本次對話提供的內容不會重問：

- **申請目標**：地區、學位、年度／梯次、管道，已有或尚未決定的系組與期限。
- **背景與方向**：學歷領域、研究興趣，以及專題、研究、工作或其他經歷概況。
- **本次工作與素材**：要選校、盤點、撰寫、排版、檢查或轉檔；已有文件、網址或指定資料夾，以及語言與輸出格式。

## 3. 準備哪些資料

先給手上已有的資料，不必先改寫成完整文章；沒有的項目可填「沒有」「未定」或「稍後補」。

| 資料 | 用途 |
|---|---|
| 官方簡章、系所分則、指定表格或網址 | 確認必繳項目、限制、上傳方式與期限 |
| 履歷、修課與成績排名資料 | 整理學習背景；需要正式數值時再核對證明 |
| 專題報告、簡報、圖片、紀錄與本人分工 | 整理具體工作、困難、成果與研究起點 |
| 競賽、學術、教學、工作等經歷與證明 | 製作相關經歷及佐證索引 |
| 舊自傳、研究計畫或其他原稿 | 接續修改，保留已確認的內容 |
| 感興趣的老師、實驗室或研究題目 | 比較研究契合；沒有時可協助探索 |

只提供本次工作必要資料。姓名、證號、住址、照片與簽章等，等具體表件需要時再處理；不需要提供登入密碼。

## 4. 製作會如何進行

1. 確認申請範圍與本次工作，盤點缺件。
2. 查核當年度官方要求，分開校方規定與個人呈現偏好。
3. 整理素材、個人分工、成果狀態及證據。
4. **自傳與研究計畫客製化之前，先查系組老師、實驗室、研究項目與近期成果**，對照個人經歷與興趣。自傳用來說明申請動機，研究計畫用來收斂問題、方法與驗證；不必預設在正文點名教授。
5. 依所需文件撰寫，處理官方表件、附件與佐證。
6. 由使用者審閱與確認事實，再依指示修訂、排版及輸出。
7. 檢查內容與實際版面，交付檔案、欄位對照及尚待完成事項。

只需要其中一階段時，可直接接續，不必每次重新做整套流程。

## 5. 常用指令範例

### 自傳與研究計畫

```text
使用 $admissions-materials，依我提供的背景與目標系組製作自傳和研究計畫。
先查官方老師及實驗室的研究內容，列出與我的經歷契合及不同的地方，再提出寫作方向。
對我的分工、成果或動機不確定時，請先向我確認。
```

### 檢查原稿，先不修改

```text
使用 $admissions-materials，檢查我提供的最新版 Word。
先不修改，請列出位置、原句、問題及建議，檢查是否通順、符合申請者視角、符合校方要求，以及是否有漏項。
```

### 只轉 PDF

```text
使用 $admissions-materials，依我剛儲存的 Word 轉成 PDF，不要改寫內容。
依我提供的校方規定處理頁數、容量與連結功能，檢查輸出頁面後告訴我哪些檢查已完成。
```

### 送件前核對

```text
使用 $admissions-materials，對照官方要求、現有檔案及我提供的系統畫面，列出每個上傳欄位對應的檔案與待辦。
請分開判斷文件完成、上傳、最後送出、推薦函完成及資格審核狀態。
```

## 6. 能得到什麼，以及使用界線

依需求產出素材／缺件清單、官方要求對照、研究契合摘要、文件初稿或修訂稿、佐證索引、可編輯檔與送件檔、上傳對照及待辦；不代表每次都會製作全部項目。

這是工作流程 Skill。查官網、讀資料夾、製作 Word／PDF 或操作網站，仍需目前環境提供相應工具與權限。只做文字內容時不要求安裝文件轉檔工具；需要檔案產製時再確認可用工具。

內容與分工需由申請者核實。研究方向契合不代表教授願意指導或保證錄取。製作文件也不等於已報名、繳費或送出；寄信、上傳及其他對外作業需另有明確指示。
